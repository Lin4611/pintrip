FORM RULES
欄位依 MVP §5.2 只有三個：收藏名稱（必填）、目的地名稱（選填）、收藏說明（選填）。順序固定，不可增刪 必填／選填以標籤右側 chip 明示（必填＝--coral-100 #FBEAE6 底、選填＝--cream-200 #F4EFE4 底，兩者文字都用 --ink-700 #3B3B3D — 底色分辨語意，文字色負責對比，實測皆 ≥ 10:1），不用星號，也不只靠顏色 送出條件名稱去除前後空白後非空才可送出。只用原生 disabled（45% 不變色、不改尺寸、不移位），不用 pointer-events 或半透明假 disabled disabled 說明CTA disabled 時，名稱欄下方出現一句 role="status" 提示並由 CTA 的 aria-describedby 指向；提示佔位出現不推走 CTA 之外的任何元素 收藏說明textarea 最小 82px、resize:none、可捲動；下方一句灰字說明它不影響分類／篩選／地圖（MVP §5.2 原文語意） 字數上限尚未決定（MVP §5.2）：不設 maxlength、不顯示計數器、不擋輸入。版面必須能承受任意長度，不得以版面限制反推產品規則 過長名稱｜輸入中input 內水平捲動，不 ellipsis、不縮字、不換行 — 使用者必須看得到自己正在打的字（與 ImportScreen 長 URL 同一條規則） 過長名稱｜顯示面截字是顯示面的責任，不是這張表單的：TripCard 標題 line-clamp 2、目標收藏列單行 ellipsis。本畫面只負責讓過長名稱不破版 不在此畫面日期、行程、封面照片、裝飾挑選一律不加。視覺樣式在建立當下自動指派（等機率抽 preset A／B／C／D），使用者無挑選入口
CREATE / EDIT 共用版式
共用同一份表單同時服務 /trips/new 與「重新命名／編輯收藏」；欄位、順序、間距、驗證與 disabled 規則完全一致 差異｜只有三處① 畫面標題（建立旅行收藏／編輯旅行收藏）② CTA 文案（建立收藏／儲存變更）③ 初始值（建立為空／編輯帶入既有值） 實作形式一個元件 + mode: 'create' | 'edit' 與 initialValues；不要複製成兩支表單，否則兩邊驗證會漂移 編輯的初始狀態帶入既有值後 CTA 可按（名稱已有值）；是否要「未變更時 disabled」尚未定案，本稿不假設 編輯不含刪除刪除收藏是破壞性動作，入口在 Home 的 ••• → 畫面層級 sheet（見 HomeScreen 的 DELETE TRIP CONFIRM），不放進這張表單 送出後導向OPEN：建立成功後是回 Home、進入該收藏，或直接接續匯入流程，尚未定案；本稿只定義表單本身與 onSubmit 邊界 視覺樣式指派建立成功的那一刻抽 preset 並持久化（HomeScreen PRESET ASSIGNMENT）；編輯既有收藏不重抽

STATE RULES
空白三欄皆空、placeholder 可見、CTA 原生 disabled、名稱下方提示出現；不預先標紅、不顯示錯誤 已填三欄有值、CTA enabled、提示消失；欄位位置與空白狀態完全一致 名稱未填目的地與說明有值但名稱空 → CTA 仍 disabled + 提示；只擋送出，不清空其他欄位 編輯｜帶入既有值標題與 CTA 換字、三欄帶入既有值、CTA 可按；版面與建立模式逐 px 相同 編輯｜過長名稱名稱 input 水平捲動、卡片不變高、無水平溢出；證明版面能承受未定上限的名稱 共通狀態切換只換值與 CTA 可用性，不換版面骨架；BottomNav 在所有狀態都存在（表單畫面不隱藏 nav） 鍵盤開啟沿用 ImportScreen 的規則：nav 隱藏、聚焦欄位與 CTA 保持可見；本稿未畫鍵盤狀態
ACCESSIBILITY
語言所有 aria-label 一律繁體中文；涉及特定收藏的動作要帶收藏名稱（編輯模式的返回鍵可用「返回」，不需帶名稱） 標籤關聯三個欄位都是真 <label for> + id，不用 placeholder 當標籤；必填欄帶 aria-required="true" disabled 原因名稱提示有 id，CTA 以 aria-describedby 指向它 — 讀螢幕的人知道為什麼不能送出，不是只看到灰掉的按鈕 提示播報提示是 role="status"（polite）；不用 alert，因為這不是送出後的錯誤，而是尚未滿足的條件 點擊區一律 ≥ 44 × 44：Back 44、CTA 48、nav 兩格 ≥ 44；欄位本身 48 高 對比必填 chip、選填 chip 與 disabled 提示的文字一律 --ink-700 #3B3B3D（≥ 10:1，達 WCAG AA）。珊瑚色不用於小字：#B5745A 於 #FBEAE6 僅 3.13:1、--coral-600 於紙色 3.36:1，皆不足；語意靠底色 + 文字，不靠色相 Focus-visible2px var(--blue-400) outline + 2px offset（欄位已留 outline-offset:2px），圓角跟隨元件 裝飾膠帶、信封、狀態列圖一律 aria-hidden + pointer-events:none 目前 mock 未實作本卡是契約：mock 的 nav 仍缺 aria-label 與 aria-current（與 Home／Import 同一筆待補），表單未包在 <form> 內、未接 Enter 送出；CTA 的 aria-describedby 目前由頁面層寫入（DS Button 以 ariaDescribedby prop 承接即可）
