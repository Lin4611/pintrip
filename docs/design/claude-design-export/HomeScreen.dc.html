React / NEXT.JS 實作建議
捲動層與固定層分離：status bar 與 BottomNav 為 fixed 層，內容區 flex:1; overflow-y:auto，可直接對應 App Router 的 layout / page 拆分。

裝飾元素（膠帶、貼紙、郵票）皆為 aria-hidden 的絕對定位圖層，不影響版位計算，可依 index 給定不同角度。
FAB 上凸由 26px 降為 14px，內容區底部留白 72px：卡片內的操作（•••、Edit）與全域「新增旅程」在視覺層級上分開，兩者不再重疊。實作時建議把 lift 值做成 BottomNav 的 fabOffset prop。
間距全部走 4px 基準（12 / 16 / 20 / 26 / 72），色彩與陰影使用 design token CSS 變數，不寫死 hex。
