切版注意事項 / PITFALLS
360px 窄螢幕
文字欄只剩約 150px。照片欄必須跟著降到 148px，否則 28px 標題會被迫兩行、footer 的數量與貼紙擠成一團。這是唯一需要 breakpoint 的地方。
Header 不要做成 grid
左右兩組都是固定尺寸美術資源，用 space-between 即可；改成 grid 或給百分比寬，430px 會出現大片空洞。
object-fit / position
照片欄是 align-self:stretch，高度隨卡片變動，比例會在 0.85–1.05 之間漂移。一律 cover + center，不要 contain，也不要用 aspect-ratio 鎖死（會與自適應高度打架）。
Line clamp
標題與說明都需要 -webkit-line-clamp:2。目前 DS 的 TripCard 沒有內建，這份 handoff 用 CSS 覆寫示範，實作時請收進元件。
Card 高度自適應
不要寫死高度。390 定稿實測 196px、長內容可到 225px，這些是量測結果而不是規格；高度一律由文字欄決定。
Category stickers overflow
footer 列必須 flex-wrap:wrap；貼紙多時整排換行，數量文字保持 nowrap。不要縮小貼紙或裁切。
Decoration positioning
裝飾必須在卡片外層，且外層不可 overflow:hidden。若把膠帶放進卡片內，卡片就無法在其他頁面重用。
BottomNav 與 FAB 層級
FAB 是 nav 的子元素而非獨立 fixed 層，才能一起吃 safe-area inset。nav 之上不要再疊 scrim 或漸層。
Horizontal overflow
長地名、長 hashtag、旋轉的膠帶都可能撐出水平捲動。捲動層 overflow-x:clip、卡片 overflow:hidden、文字欄 min-width:0 三者要同時具備。
React / NEXT.JS
AppShell 放在 layout：狀態列安全區 + 捲動 slot + BottomNav。Home 與 Import 共用同一個 shell，切頁時 nav 與 FAB 不重繪、不跳動。
Home 只有一個列表區塊會因狀態改變：normal / empty / loading / error 皆渲染在同一個容器內，外框與間距不動，避免 layout shift。
TripCard 只接資料 props；裝飾由 TripCardSlot 依該收藏集建立時已持久化的 decorPreset（A／B／C／D）渲染 — 不看 card index、不看 render order、render 時不重新隨機；缺欄位時 fallback C。兩者責任分離，卡片可在其他頁面直接重用。
兩個 DS 覆寫建議收回元件：BottomNav 的 fabOffset（14px）與 TripCard 的 photoWidth + line-clamp。目前以 CSS 覆寫呈現，僅為 handoff 示範。
間距全部走 4px 基準（6 / 10 / 12 / 14 / 16 / 20 / 26 / 72），色彩、圓角、陰影一律使用 design token CSS 變數，不寫死 hex。
圖片用 next/image 時需給 sizes（照片欄 148/172/196），並保留 fill + object-cover；裝飾類 PNG 不進 next/image，直接 img + aria-hidden。
