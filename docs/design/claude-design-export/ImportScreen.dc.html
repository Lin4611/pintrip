React / NEXT.JS 實作建議
與 Home 共用同一個 AppShell：status bar 與 BottomNav 放 layout，畫面內容放 page，兩頁的固定層完全不重繪，切頁時 nav 不跳動。
三段狀態（idle / analyzing / done）只切換 AnalyzeStatus 與結果區塊，LinkInput 與 CTA 位置不動；analyzing 用 opacity 淡入，不要位移或骨架跳動。
結果卡片的「編輯 / 加入旅程」是卡片內操作，加入後只換標籤為「已加入 ✓」，按鈕不消失、卡片高度不變。
底部珊瑚色 CTA 是全頁唯一 commit 動作，與卡片內的藍色按鈕不可同色，也不要在同一畫面出現第二顆珊瑚色按鈕。

切版注意事項
圖片裁切比例
結果卡片照片固定 120×136（約 0.88:1），一律 object-fit:cover + object-position:center；白色相框是外層 padding，不要用 border 疊圓角，否則不同 DPR 下會露出邊。來源圖多為橫幅，交付時請提供中心可裁切的版本。
Sticker / Tape 定位
裝飾一律是卡片外層 position:relative 容器內的 absolute 圖層，用 top/left 加上 rotate(−8°~+7°)，並跨過卡片邊界才有壓住紙張的感覺。全部 aria-hidden 且 pointer-events:none，不可放進卡片元件內部，否則卡片無法重用。
Card 高度自適應
卡片不設固定高度：描述最多 2 行、地址 1 行，超出用 line-clamp；標籤列用 flex-wrap 並允許換行到第二行。中／韓文較長時左右欄高度差異大，改動時請以照片高度為最小高度基準。
BottomNav 與 FAB 層級
nav 容器 z-index 5、FAB 上凸 14px 且帶 5px 米色描邊；捲動內容不可高於 nav。內容區底部保留 72px 留白，避免最後一顆 CTA 被 FAB 蓋住。
Mobile safe area
nav 高度用 72px + env(safe-area-inset-bottom)，底部 padding 同步加上 inset；iOS 鍵盤升起時 LinkInput 需 scroll into view，但 nav 應維持在版面底部而非跟著鍵盤。
Overflow scroll
只有內容區可捲動（flex:1; overflow-y:auto; overscroll-behavior:contain），frame 本身 overflow:hidden；捲軸隱藏但需保留鍵盤與 tab focus 的可捲動性。裝飾貼紙不可造成水平捲動，必要時外層 overflow-x:clip。
